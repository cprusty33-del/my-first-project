Income Tax Library MCP — Setup Guide

Five steps, about ten minutes, on your own Windows PC. After this, Claude can search your Income Tax Library subscription and draft appeals and replies from what it finds.

About the pictures below. They are drawings of what the Edge windows look like, drawn to match the buttons and panels you will see. They are not photographs of your account — this setup was prepared on a machine that cannot open incometaxlibrary.com, and a faked screenshot of your own site would only mislead you.

Before you start

You needHow to check
Node.js 18 or newerOpen PowerShell, type node -v. If it says "not recognized", install from nodejs.org.
The project folder on your PCThe folder containing mcp-servers\income-tax-library.
A working Income Tax Library loginYou can open the dashboard in Edge without being asked to sign in.
1

Open PowerShell in the right folder

In File Explorer, open your project folder, then the mcp-servers folder, then income-tax-library. Click once in the address bar at the top, type powershell and press Enter. A black window opens, already pointing at the right place.

Type this and press Enter:

npm run setup

It creates your settings file and tells you what is still missing. You will see a line saying ITL_COOKIE: NOT SET. That is expected — step 3 fixes it.

2

Log in to the site in Microsoft Edge

Open incometaxlibrary.com in Edge and sign in as usual, until you can see your dashboard (the page with "IMPORTANT CASE LAWS"). Leave this tab open.

3

Copy your session line (the "Cookie")

This is the only fiddly step. It tells the program "use the same login the browser is already using."

3a. With the dashboard on screen, press F12. A panel opens on the right or bottom. Click the tab named Network.

3b. Press F5 to reload the page. The list fills up. Click the first row in that list (usually named dashboard).

3c. On the right, click Headers, scroll down to the section Request Headers, and find the line beginning Cookie:. Right-click that line and choose Copy value.

3d. Back in PowerShell, type the line below — type the opening quote, press Ctrl+V to paste, then type the closing quote and press Enter:

$env:ITL_COOKIE = "paste-the-copied-line-here"
Treat this line like your password. Anyone holding it can use your subscription until it expires. Do not email it, do not paste it into a chat, and do not commit it to the project. It lives only in that PowerShell window.
4

Let the program learn the site by itself

In the same PowerShell window:

npm run discover -- --write

It opens your dashboard with your login, reads the search box and the case-law links that are really on the page, tries each one, and saves what actually worked. You will see a block of text ending with a list called chosen.

Reading the result. "chosen" lists what it worked out. "unresolved" lists what it could not — usually because that part of the site loads its results in a way a plain page read cannot see. If anything is unresolved, send me that block of text and I will fill in the missing piece by hand.

If it says every page is a login wall, your cookie has expired or was pasted incompletely. Repeat step 3.

5

Tell Claude about the server (once)

claude mcp add income-tax-library -- node "$PWD\server.js"

Close and reopen Claude Code. Type /mcp — income-tax-library should appear in the list.

Using it

Ask in plain words, for example:

  • "Find Income Tax Library case laws on immunity under section 270AA where penalty was for misreporting."
  • "Pull the full text of the third result and save it as an authority."
  • "Draft a CIT(A) appeal in Form 35 for AY 2018-19 using those authorities. Facts: …"

The draft comes back with [TO BE FILLED: …] wherever you have not given a fact — those blanks are deliberate. Nothing is invented to fill them.

What you seeWhat it meansWhat to do
ITL_COOKIE: NOT SETThe PowerShell window was closed and reopened.Repeat step 3d in the new window.
Results look like a login pageThe cookie expired.Repeat step 3 from the start.
endpoint "search" is not configuredStep 4 has not run, or found nothing.Run step 4; if unresolved, send me the output.
npm is not recognizedNode.js is not installed.Install Node.js 18+ from nodejs.org, reopen PowerShell.

Two standing cautions

  • The cookie expires — expect to repeat step 3 every so often. That is normal, not a fault.
  • Every draft is a skeleton with your facts in it. Limitation periods, fees, pre-deposit and the form in force for the relevant year remain yours to verify before filing.
